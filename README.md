# Indian Artisan Discovery

A demo website for exploring Indian artisans and raw materials by region, craft, and experience level.

## Live Demo

Deploy to GitHub Pages — just push this repo and enable Pages from the `main` branch root.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Main page structure |
| `style.css` | All styles |
| `data.js` | Artisan (200) + Raw Materials (50) data |
| `app.js` | Filter logic and rendering |

## Features

- Filter by **Region / City** (e.g. Jaipur, Bastar, Srinagar)
- Filter by **Craft Type** (15 crafts)
- Filter by **Experience Level** (Beginner / Intermediate / Expert)
- **Search by name** in real-time
- Shows matching **Artisans** with Sl. No, Name, Craft, Location, Years of Experience
- Shows matching **Raw Materials** with Material Name, Associated Craft, Sourcing Region
- Live result count
- Fully static — no backend needed
